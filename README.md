# Skygrid

A port of the iconic Minecraft Skygrid worldgen to **Vintage Story 1.22.2**.

The whole world becomes a 3D grid of random blocks separated by air. You start
on a single suspended cell with a basket at your feet and must climb, bridge,
and salvage your way across the void to scattered loot containers and the
vintage's story structures, now floating as preserved islands.

**Side:** `server` — no client install needed. Drop the zip into your server's
`Mods/` folder and your players can connect with vanilla 1.22.2.

---

## Worldgen

| Setting                 | Value          | Notes                                                      |
| ----------------------- | -------------- | ---------------------------------------------------------- |
| Grid spacing            | 4              | One block every 4 blocks on each axis. Three air gaps between. |
| Vertical band           | Y = 30 … 250   | Below the band is solid void floor, above it is open sky.  |
| Containers per column   | 1 … 128        | Every generated chunk-column hosts at least one container. |
| Loot scaling cap        | 5 000 blocks   | Per-table pick count scales 1.0× near spawn to 2.0× past this distance. |

### Palette balance — three pools

The candidate-block palette is split by navigability so the grid is climbable
without you constantly hitting a fence or a flower.

| Pool         | Selection criteria                                         | Roll chance |
| ------------ | ---------------------------------------------------------- | ----------- |
| Navigable    | FullCube **or** SolidTop, non-liquid                       | **87 %**    |
| Decorative   | Partial collision **or** NoCollision non-liquid (fences, plants, deco) | 10 %        |
| Liquid       | Water / lava / saltwater / rapidwater / boilingwater (still-7 source variant only) | 3 %         |

Filtered out entirely: entity-class blocks, creative-mod blocks
(`creativeblock*`, `creativeglow*`, `creativelight*`, …), `-raw` ore variants,
`Unplaceable` blocks, and non-source liquid variants (so no flowing water
nightmare).

## Story structures preserved as vintage islands

Vintage Story 1.22.2 has 6 story structures total. **5 of them are preserved**
as full vintage chunks inside the skygrid void, tied to the lore arc:

| Code               | Role                          |
| ------------------ | ----------------------------- |
| `lazaret`          | Entry point of the story arc  |
| `village`          | Tobias' village               |
| `tobiascave`       | Tobias' hideout               |
| `devastationarea`  | End-game devastation zone     |
| `resonancearchive` | Side branch (deep archive)    |

The 6th story structure (`treasurehunter`, standalone side-content) is **not**
preserved — its chunks get wiped to grid like any other dungeon.

Non-story content (translocators, tiled dungeons, surface ruins, villages
generated by regular worldgen) is also wiped to grid. Only the 5 codes above
survive.

### Translocator-gate network

In a skygrid you can't walk 8 000 blocks of void to reach the lazaret, so the
mod wires the canonical progression into a pre-fixed network of static
translocators.

**Topology — 5 legs, fully bidirectional:**

```
spawn ─── lazaret ─── village ─── tobiascave ─── devastationarea
   │
   └─── resonancearchive
```

Per leg: **5 dedicated pairs** of gates (`GatesPerLeg = 5`), giving **10
gates per leg** total. Each source gate is matched with one exit gate near the
destination, and each exit is itself a return gate pointing back to its
specific source — so any of the 5 source gates near A delivers you to its
matching exit near B, and vice versa.

**All gates are placed pre-repaired** (`canTele=true, repairState=4,
activated=true, findNextChunk=false`). You walk into one, it works
immediately, no repair grind.

Each gate sits on a 3×3 platform of `creativelight-79` (max light level 22)
laid one block below the gate — so the gate site is visible from the void at
distance and the platform doubles as a landing pad.

**Gate placement distances:**

| Code               | Distance rule                                              |
| ------------------ | ---------------------------------------------------------- |
| `spawn`            | Fixed ring radius **200 blocks** from world spawn          |
| `lazaret`          | Fixed ring radius **100 blocks** from its center           |
| `resonancearchive` | **100 blocks beyond bbox edge** (bbox is ~200×170 underground) |
| `village`          | **100 blocks beyond bbox edge**                            |
| `tobiascave`       | **100 blocks beyond bbox edge**                            |
| `devastationarea`  | **100 blocks beyond bbox edge**                            |

All gates are snapped to **sea level Y** so arrivals are predictable across
the network. Y is rounded down to the nearest grid step (every 4 blocks) so
the gate lands on a real grid cell.

## Container tiers

Each chunk-column rolls 1 to 128 containers. Each container picks a tier (with
distance-weighted bias toward higher tiers far from spawn), then picks one
loot table from that tier.

| # | Tier         | Block (preferred)               | Slots | Default weight | Weight @ 1 000 b | Weight @ 2 000 b |
| - | ------------ | ------------------------------- | ----- | -------------- | ----------------- | ----------------- |
| 0 | **Basket**   | `stationarybasket-east`         | 8     | 0.30           | 0.10              | 0.10              |
| 1 | **Chest**    | `chest-east`                    | 16    | 0.30           | **0.40**          | 0.10              |
| 2 | **Trunk**    | `trunk-east` (fallback `chest-east`) | 36 | 0.10           | 0.20              | 0.10              |
| 3 | **Animal Chest** | `chest-east`                | 16    | 0.20           | 0.10              | 0.10              |
| 4 | **Vessel**   | `storagevessel-{cream,brown,blue}-fired` (fallback `chest-east`) | 12 | 0.10 | 0.20 | **0.60** |

The bias is intentional:
- **Near spawn (< 1 000 b):** lots of baskets and chests, some animals — the
  player needs food, tools and seeds first.
- **Mid-range (1 000–2 000 b):** chests dominate, trunks tier up — bloomeries,
  forges, workshops.
- **Far (> 2 000 b):** vessels dominate — refined metals, gems, mechanical
  power become the reward for the trek.

Containers also get a **distance-based item-count multiplier**: 1.0× near
spawn, scaling linearly up to **2.0× at 5 000 blocks** from spawn (cap).

### Tier 0 — Basket (per-player + scattered)

A `stationarybasket-east` (8 slots), used both as a **starter basket** placed
next to each player on first join (persisted per-player so it never re-spawns)
and as the lowest container tier scattered throughout the grid.

Pool — picks **6 to 8 distinct entries** per basket (75 %–100 % full):

- **Food** (raw, will rot — designed to sustain a few days before going to
  mold): carrot, onion, parsnip, turnip, cabbage, soybean, raw redmeat & bushmeat,
  perfect spelt bread, salt
- **Wood**: oak / birch / pine / maple logs, sticks, aged planks
- **Clay**: blue, red, fire (early-game pots, kilns, vessels)
- **Reed roots**: cattailroot, papyrusroot (edible + rope crafting)
- **Other**: low-fertility soil, oak treeseed, flax & carrot seeds, flint

### Tier 1 — Chest (multi-table)

A `chest-east` (16 slots). Picks one of **5 tables** per chest:

| Table              | Weight | Picks      | Theme                                                  |
| ------------------ | ------ | ---------- | ------------------------------------------------------ |
| Tool Cache         | 1.0    | 6 – 10     | Flint set, copper/tinbronze hammers, prospecting pick, knife, pickaxe, shears, firestarter |
| **Food Cache**     | **2.5**| **12 – 16**| **75 %–100 % full of food** — vegetables, grains, raw meats, breads, mushrooms, fruits, pickles, salt, fat, raw hide |
| Seeds & Saplings   | 1.0    | 6 – 10     | Tree seeds (oak/pine/birch/maple/acacia/redwood/kapok), crop seeds |
| Early Metal        | 1.0    | 6 – 10     | Copper/cassiterite/limonite/sphalerite nuggets, copper & tinbronze ingots, charcoal, hammers, tongs |
| Building Materials | 1.0    | 6 – 10     | Granite/andesite/basalt/chalk/sandstone, logs, planks, charcoal, fired claybricks |

Food Cache is **deliberately overweighted (2.5×)**: early-game survival
depends on this stockpile while you set up ferments and farms. The food rots
into mold over time, so the early-game value is a hard window.

### Tier 2 — Trunk (multi-table)

A `trunk-east` (36 slots). Picks one of **4 tables**:

| Table         | Weight | Picks    | Theme                                                  |
| ------------- | ------ | -------- | ------------------------------------------------------ |
| Forge Kit     | 0.5    | 12 – 20  | Firepit, copper anvil, iron anvil parts, ingot molds, hammers, tongs, copper/tinbronze/bismuthbronze ingots, native copper, charcoal |
| Bloomery Kit  | 0.5    | 10 – 16  | Bloomery + helve hammer + pulverizer + forge + clay oven, iron anvil & hammer, iron ingot, limonite nuggets, charcoal, grindstone |
| Storage Kit   | 1.0    | 10 – 16  | Chests, labeled chests, trunks, barrels, vessels, baskets, lanterns, torchholders, signs, doors, trapdoors, tapestries, toolracks |
| Workshop Kit  | 1.0    | 10 – 16  | Quern, clay planters, flowerpots, displaycases, scrollrack, bookshelf, berry bushes, woodbucket, trapcrate, locust-nest cage, ingots, clay |

### Tier 3 — Animal Chest

A `chest-east` (16 slots) that holds **creature spawn entries**. Picks one of
**2 tables**:

- **Passive Animal Creatures** (2–4 picks): chicken hen/rooster, eurasian pig,
  bighorn sheep, mountain goat, european hare — adult M/F variants
- **Aggressive Animal Creatures** (2–4 picks): eurasian wolf, spotted hyena,
  brown/black/polar bear — adult M/F variants

### Tier 4 — Vessel (high-tier)

A `storagevessel-*-fired` (12 slots), placed on a solid support block (because
storage vessels are `UnstableFalling` and would drop into the void without
one). Picks one of **3 tables**:

| Table                          | Picks | Theme                                                       |
| ------------------------------ | ----- | ----------------------------------------------------------- |
| Treasure: Refined Metal        | 4 – 8 | Iron / meteoric-iron / steel / blistersteel / gold / silver / electrum / cupronickel / platinum ingots, native gold & silver nuggets, raw meteorite |
| Treasure: Gems & Rare          | 4 – 8 | Rough diamond, emerald, peridot, gold ingots & nuggets       |
| Treasure: Mechanical Power     | 4 – 8 | Water wheel, windmill rotor, axles, gears, brake, clutch, transmission, large gear, hopper, chutes, copper & iron ingots |

## Starter basket

The first time each player joins the server, the mod queues a starter basket
to spawn one block to the east of their feet. The basket uses the **Tier 0
Survival Starter** table (the same one scattered throughout the grid), so the
player always opens with a real food + wood + clay + cattailroot stockpile.

The "already given" state is persisted under `vsmodskygrid.spawnchest.{uid}`
in savegame data — the basket is one-shot per player, and the queue retries
on game-tick if the player's chunk wasn't loaded yet at join time.

## Installation

1. Download `vsmodskygrid-X.Y.Z.zip` from the
   [Releases page](https://github.com/Eloi-Desbrosses/VsModSkygrid/releases).
2. Drop the zip into your VS server's `Mods/` folder.
3. Start a **new world** (skygrid only generates new chunks — it does not
   convert existing terrain).
4. Players can connect with a stock Vintage Story 1.22.2 client. No client
   mod is needed.

## Building from source

```sh
docker compose run --rm build
```

Output: `build/VsModSkygrid.dll` + `build/modinfo.json`.
